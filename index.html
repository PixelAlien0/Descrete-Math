Duality Principle

To construct the dual of any compound proposition involving only ∧ and ∨, execute strict replacements: replace ∧ with ∨, ∨ with ∧, T with F, and F with T.

Dual of: (p ∧ q) ∨ p  →  (p ∨ q) ∧ p

Dual of: (p ∨ F) ∧ q  →  (p ∧ T) ∨ q

Replacement Rule

If two propositions are logically equivalent (P1 ≡ P2), you can substitute P2 for P1 anywhere inside a larger compound statement without changing the truth value of the overall expression.

Derivation Example: Prove (p ∧ q) ∨ (p ∨ q) ≡ p
1. (p ∧ q) ∨ (p ∧ q)   [De Morgan's Laws]
2. p ∧ (q ∨ q)         [Distributive Laws]
3. p ∧ 1                   [Complement Laws]
4. p                        [Identity Laws]

Conditionals Matrix

Given the conditional proposition p → q ("If Jack plays his guitar, then Sara will sing"), we evaluate its 3 structural permutations:

Converse q → p

"If Sara will sing, then Jack plays his guitar."

Inverse p → q

"If Jack doesn't play his guitar, then Sara won't sing."

Contrapositive q → p

"If Sara won't sing, then Jack doesn't play his guitar."

Lesson 6 Notes

Predicate Logic

First-Order Predicates

A predicate is a sentence containing variables that becomes a declarative proposition once specific entities are substituted. Capital letters are used for predicates; lowercase letters at the beginning of the alphabet act as constants (specific entities like m for Mary), and those at the end act as variables (x, y, z).

Multi-Variable Relations

Predicates can describe properties of multiple variables simultaneously.

L(x, y, z): x lent y to z
O(x, y): x lost y

"Alice lent a book to Bob, but Bob lost it":
L(a, o, b) ∧ O(b, o)

Mnemonic Constants & Predicates

Choosing letters corresponding to English names makes translations much easier to read.

Constants: m = Mary, j = John, p = Paul

Predicates: S(x) = "x is a suspect", A(x) = "x has an alibi"

"If Mary knows John, then Mary has no alibi":

K(m,j) → A(m)

Universal Quantification (∀)

∀

Specifies that the property holds true for every entity in the domain.

"Every student who studies hard will pass":

∀x [(S(x) ∧ H(x)) → P(x)]

"No cats are reptiles":

∀x [C(x) → ¬R(x)]

Existential Quantification (∃)

∃

Specifies that the property holds true for at least one entity in the domain.

"Some children didn't apologize":

∃x [C(x) ∧ ¬A(x)]

"Some people think of no one but themselves":

∃x [P(x) ∧ N(x)]

Lesson 7 Notes

Boolean Algebra & Gates

What is Boolean Algebra?

Unlike standard algebra which deals with infinite numbers, Boolean Algebra only deals with two states: 1 (True/High) and 0 (False/Low). It is the mathematical foundation of all modern computer circuits.

By connecting tiny physical switches (transistors) in specific patterns on a microchip, we can physically compute logical operations.

Operator Precedence

Just like PEMDAS in regular math, Boolean logic has a strict order of operations to prevent ambiguity when reading equations:

1 Parentheses ( )
2 NOT (Complement) A
3 AND (Multiplication) ·
4 OR (Addition) +

Circuit Minimization (Why do we care?)

Building computer chips costs money. Every logic gate requires physical space and electricity. Minimization is the process of using algebraic laws to reduce a complex equation into a simpler one that achieves the exact same output, but requires far fewer hardware gates.

Step-by-Step Minimization Example

Let's simplify the circuit design for the equation: F = A·B + A·B

1. A·B + A·B ← Original equation (Requires 2 AND gates, 1 NOT gate, 1 OR gate)
2. A · (B + B) ← Factor out 'A' using the Distributive Law backwards.
3. A · (1) ← (B + B) is always 1 (True) thanks to the Complement Law.
4. A ← A AND 1 is just A (Identity Law). We reduced 4 gates down to ZERO gates! (Just a wire).

Canonical Declarations

A Boolean function is represented canonically in either Sum-of-Products (SOP) form (constructed by OR-ing Minterms) or Product-of-Sums (POS) form (constructed by AND-ing Maxterms). Think of Canonical forms as the mathematical "standardized blueprints" extracted directly from a Truth Table before any minimization happens.

Understanding Minterms vs. Maxterms

Imagine analyzing a single row in a truth table where A=1, B=0, C=1.

  • Minterm (Used for SOP): We want an expression that equals exactly 1 for this row. We multiply (AND): A · B · C. Notice how we put an overbar on B to flip it from 0 to 1 so the whole statement is true.
  • Maxterm (Used for POS): We want an expression that equals exactly 0 for this row. We add (OR): A + B + C. The logic is reversed! We put overbars on A and C to force them to 0.

SOP Minterm Translation Rules

Minterms represent rows evaluating to 1. If a variable's value is 0, add an overbar (primed/complemented). If the variable's value is 1, keep it unprimed.

POS Maxterm Translation Rules

Maxterms represent rows evaluating to 0. If a variable's value is 0, keep it unprimed. If the variable's value is 1, add an overbar (primed/complemented).
